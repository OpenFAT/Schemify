# Testing (binding, D37)

Methodology: `../../Zig/TESTING-METHODOLOGY.md` (oracles before coverage; several independent oracles per area; assertions are the fuzzer's oracle; deterministic seed-replayable randomized tests; coverage as a gap-finder; mutation testing; tiers; exit criteria). Rust tools: `proptest`, `cargo-fuzz` + `arbitrary`, `cargo-mutants`, `cargo-llvm-cov` (ratchet only).

**Every feature lands with its oracle in the same change.** Every user or LLM bug report becomes a new oracle or generator feature, not just an example test.

## Oracles per area

| Area | Oracle(s) |
|---|---|
| `format` | Property: `parse(write(doc)) == doc`; `write` canonical and idempotent (`write(parse(s)) == s` for canonical `s`); any reorder of rank-3 records parses to the same model. Fuzz the reader: no panic, errors only from the declared set. `merge3`: non-conflicting edits commute (`merge(O, A, B) == merge(O, B, A)`), `merge(O, A, O) == A`, model-based PBT over random edit scripts. |
| `expr` | Differential vs a naive tree-walking reference evaluator written only for tests; differential vs ngspice for the SPICE-compatible subset; properties: canonical number text round-trips (`num(str(x)) == x`); dependency-graph recompute == full recompute after random edits. Fuzz parser. |
| `doc` | Stateful model-based PBT: random edit sequences vs a naive model; undo-all == original; journal replay after a simulated crash at every op == pre-crash state (seeded, DST-style); load(save(x)) == x. |
| `elab` connectivity | Reference: naive O(n²) union-find over all point pairs vs the real extractor. Metamorphic: translate / rotate / mirror the whole schematic, permute record order, re-id objects → identical nets (modulo `net_<id>` naming, compared as partitions). |
| `elab` params/gating | Exhaustive small domains for min/max/grid/choices; waiver toggles flip only E→I for the named param. |
| `netlist` | **Differential vs xschem:** golden netlists from *running* xschem on the corpus (sky130, gf180, IHP, xschem examples), compared semantically (flattened connectivity partitions + evaluated params, order/name insensitive). **Second oracle:** ngspice results of ours vs xschem's netlist agree within tolerance. Metamorphic: hierarchical vs flattened → same sim results; renaming an unlabeled net never changes emitted labeled nets. Determinism: byte-identical across platforms and runs. |
| `import` | Fuzz all readers (xschem .sch/.sym, model cards, tech files, cdfDump) seeded with real PDK files; every unknown construct lands in `needs_review`, never silently dropped (assert count conservation: records in = records out + needs_review); re-import of unchanged input → empty diff. |
| `wave` | Binary vs ASCII `.raw` of the same sim agree (ngspice and Xyce fixtures: tran, AC, stepped DC); calculator metamorphic (`integ(deriv(y)) ≈ y − y0`, linearity) on real data; ngspice vs Xyce and AC vs closed form; fuzzed reader (no panic, declared errors only); SIMD decimation vs its scalar oracle; viewer requests (zoom/pan inverses, box zoom, autoscale cover). |
| `run` | Analytic optima for the optimizer; MC sample statistics within confidence bounds; `jobs=1` vs `jobs=N` byte-identical results. |
| `plugin` | Stateful fuzz of request tables: stale handles, conflicting edits, capability violations → declared errors only. The default-UI plugin is the conformance test. |
| `ui`/`render` | Golden images (vello CPU vs GPU within tolerance); UI table → AccessKit tree snapshot. |

## Corpus

`tests/corpus/` holds only scripts and small hand-written fixtures. Third-party inputs (PDK libraries, xschem examples) are **fetched at pinned revisions** by `tests/corpus/fetch.sh` into `tests/corpus/.cache/` (gitignored); goldens are generated by running a pinned xschem (`nix`) via `tests/corpus/golden.sh`. Nothing GPL is vendored.

## Tiers

| Tier | Runs |
|---|---|
| pre-commit | `cargo test -p <touched crates>` |
| merge | full workspace tests on Linux/macOS/Windows/Web(wasm32), fuzz-corpus replay, determinism check (byte-identical netlists across platforms) |
| nightly | fuzzing 1 h/target, xschem + ngspice differential on the full corpus, `cargo mutants` on changed crates, coverage ratchet, benchmarks vs D39 budgets (fail on > 10% regression) |
| release | ≥ 24 CPU-h fuzzing per target, full differential, checklist |

## Release exit criteria

Corpus 100% pass with only annotated XFAILs; fuzzers ≥ 24 CPU-h per target with no new crash and a plateaued corpus; xschem-differential agreement count ≥ previous release with every difference triaged; byte-identical outputs on all four platforms; coverage not below the last release; D39 budgets met; known-gaps list written.

## Code rules that feed the oracles

TigerStyle asserts (≥ 2 per function on average, positive and negative space); bounded loops and queues; every table has a capacity.
