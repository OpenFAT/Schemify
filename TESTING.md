# Testing (binding, D37)

Methodology: `../../Zig/TESTING-METHODOLOGY.md` (oracles before coverage; several independent oracles per area; assertions are the fuzzer's oracle; deterministic seed-replayable randomized tests; coverage as a gap-finder; mutation testing; tiers; exit criteria). Rust tools: `proptest`, `cargo-fuzz` + `arbitrary`, `cargo-mutants`, `cargo-llvm-cov` (ratchet only).

**Every feature lands with its oracle in the same change.** Every user or LLM bug report becomes a new oracle or generator feature, not just an example test.

## Oracles per area

| Area | Oracle(s) |
|---|---|
| `format` | Property: `parse(write(doc)) == doc`; `write` canonical and idempotent (`write(parse(s)) == s` for canonical `s`); any reorder of rank-3 records parses to the same model. Fuzz the reader: no panic, errors only from the declared set. `merge3`: non-conflicting edits commute (`merge(O, A, B) == merge(O, B, A)`), `merge(O, A, O) == A`, model-based PBT over random edit scripts; verbatim diff3: line edits separated by a line both sides keep merge to both edits applied, symmetrically; a clean result that breaks the kind rules conflicts. |
| `expr` | Differential vs a naive tree-walking reference evaluator written only for tests; differential vs ngspice for the SPICE-compatible subset; properties: canonical number text round-trips (`num(str(x)) == x`); dependency-graph recompute == full recompute after random edits; one-pass cycle report vs naive reachability (cycles real, covering exactly the self-reaching nodes; acyclic order == `topo_order`). Fuzz parser. |
| `doc` | Stateful model-based PBT: random edit sequences vs a naive model; undo-all == original; journal replay after a simulated crash at every op == pre-crash state (seeded, DST-style); load(save(x)) == x; the ops `apply_edits_report` returns, committed to a mirror, reproduce every request's result. |
| `elab` connectivity | Reference: naive O(n²) union-find over all point pairs vs the real extractor. Metamorphic: translate / rotate / mirror the whole schematic, permute record order, re-id objects → identical nets (modulo `net_<id>` naming, compared as partitions). |
| `elab` params/gating | Exhaustive small domains for min/max/grid/choices; waiver toggles flip only E→I for the named param. |
| `netlist` | **Differential vs xschem:** golden netlists from *running* xschem on the corpus (sky130, gf180, IHP, xschem examples), compared semantically (flattened connectivity partitions + evaluated params, order/name insensitive). **Second oracle:** ngspice results of ours vs xschem's netlist agree within tolerance. Metamorphic: hierarchical vs flattened → same sim results; renaming an unlabeled net never changes emitted labeled nets. Determinism: byte-identical across platforms and runs. **Verilog** (no xschem golden): Icarus Verilog parses and elaborates every fixture netlist of the dialect (`netlist/tests/iverilog.rs`, CI installs `iverilog` on Linux; a missing module or port fails it). **Spectre**: snapshots only, no second oracle: no Spectre-syntax simulator runs in CI (Spectre is proprietary; ngspice and Xyce read SPICE syntax). |
| `import` | Fuzz all readers (xschem .sch/.sym, model cards, tech files, cdfDump) seeded with real PDK files; every unknown construct lands in `needs_review`, never silently dropped (assert count conservation: records in = records out + needs_review); re-import of unchanged input → empty diff. |
| `wave` | Binary vs ASCII `.raw` of the same sim agree (ngspice and Xyce fixtures: tran, AC, stepped DC); calculator metamorphic (`integ(deriv(y)) ≈ y − y0`, linearity) on real data; ngspice vs Xyce and AC vs closed form; fuzzed reader (no panic, declared errors only); SIMD decimation vs its scalar oracle; viewer requests (zoom/pan inverses, box zoom, autoscale cover); readouts (per step, tracked step) vs a reference interpolator; digital lanes vs a naive per-column oracle, thresholding metamorphic (shared scaling/offset of signal and threshold, negation complements), buses equal their thresholded bits; histogram bins conserve and add up; fft and per-step traces keep their own x axis; the graph properties dialog round-trips (OK on an unchanged dialog changes nothing, seeded cases); reload keeps the traces that still evaluate. |
| `run` | Analytic optima for the optimizer; MC sample statistics within confidence bounds; `jobs=1` vs `jobs=N` byte-identical results. |
| `plugin` | Stateful fuzz of request tables: stale handles, conflicting edits, capability violations → declared errors only. The default-UI plugin is the conformance test. Composition vs a naive model (last wins, redefinitions drop earlier `set`s); events on a worker produce exactly the synchronous outputs, faults and composition; `QUARANTINE_AFTER` aborts in a row drop a plugin, one good call resets the count; the guests' lexer agrees with the format reader on random lines; `eval` answers equal elab's cell values. |
| `rpc` (command stream, D27) | Codec: `parse(write(v)) == v` for generated JSON (property), RFC 8259 accept/reject cases; any bytes decode to a request or a declared `-32700`/`-32600` response, never a panic (property + `cli/fuzz` `rpc_decode`). Headless: every listed method reachable; CLI methods answer the CLI's own exit code and output (the binary as oracle); `edit` changes exactly the edited record (`schemify diff` as oracle) and leaves the file alone on invalid ops; garbage never stops the stream; the Unix socket answers like stdio. Editor: every command the table lists is queued (core, plugin, suffix arguments), unknown names and bad params are declared errors; a socket client drives the frame spine and receives answers in order and `event` notifications. MCP bridge: lifecycle, `tools/list` = the headless methods, failing tools as `isError` results. |
| `ui`/`render` | Golden images (vello CPU vs GPU within tolerance); UI table → AccessKit tree snapshot. Canvas raster cache (D39, `render/tests/cache.rs`, `gpu.rs`): a copied, stretched or patched layer vs a direct render or a fresh recording over seeded walks of pans, zooms and edits (patched within 1 level per channel on the CPU), withheld damage shows stale pixels; tiles at far zooms (level of detail) and tiles recorded in parts over frames equal a direct render pixel for pixel; `PrimIndex` queries cover every row whose box meets the query; composed (vello-free) frames vs vello frames; the row diff vs a quadratic LCS. Incremental scene == full build over random edits incl. shapes, rotated texts and undo/redo (`app/tests/scene.rs`); the editor's kept canvas == a fresh recording under random selections, deletes, undo/redo, drawn shapes and view-option toggles (`app/tests/canvas.rs`). |
| docs page (D19–D21) | Incremental recompute == fresh `CellState` build, including `cached` edits on vars and params (`elab/tests/incremental.rs`); plugin string results owned and their caches quoted (`elab` values); a docs-page edit plus its cache write-back is one undo entry and one journal `tx` record with no undo/redo records (`Edit::Extend`); param defaults cached like vars, stale caches dropped with a changed expression with and without the plugin; plot slots overlay every sweep point and reach cells two levels below the bench, not cells outside it (`app/tests/sim.rs`); headless edits through the frame spine against the canonical file (undo restores it byte for byte; one edit = one undo, cache write-back included); D20 paths (no plugin → cached + unverified, stale hash → rewrite); values vs the plugin's own sample checks; CPU golden of a page (prose, inline/display math, var rows); prose: footnote numbering, links keeping their emphasis, table columns from content (`column_widths` cases), images scaled to the width and refused outside the project or when not PNG (`app/tests/docs.rs`), a text area scrolling inside itself (`ui/tests/ui.rs`); D39 var edit with 1k dependents in `app/tests/perf.rs`. |
| editor integration (M2) | Through the frame spine (`app/tests/sim.rs`): the checks overlay equals elab's violations (one mark per row, one marker per drawn object) before and after an edit and its undo; net highlight equals elab's net membership (components carrying the bit), also one level down through a port; `n` writes the bytes `schemify netlist` prints (CLI as oracle) and refuses on an `E` row; a fake `sh` simulator run completes through ticks only (starting it takes < 250 ms), results equal the analytic fake (tau = 0.632/R), the plot slot becomes a graph, OP marks equal the fake's operating point, cross-probe adds `v(out)`, results reload from disk and go stale after an edit; optimizer best point = the job with the smallest goal error, staged then accepted (file changes) or rejected (file unchanged); plugin `run` → `RunDone` for that plugin; no tick scheduled when idle; real ngspice: tau = RC within 0.5%. |
| `plugins/gmid-lut` | LUT queries vs the analytic EKV model it was generated from (bisection at full precision, ≤ 2%), at the nominal VDS and off it (`_at` functions; at the nominal VDS they equal the plain ones bit for bit); a synthetic gm/Id dip is crossed (answers past it, VGS still monotone); monotonicity (jd, VGS, ft fall and W grows with gm/Id; gain grows, ft falls with L); `.glut` round trip; no panic on every truncation, random byte flips and oversized headers; the built wasm vs the native evaluator through wasmi, within the default fuel. |

## Corpus

`tests/corpus/` holds only scripts and small hand-written fixtures. Third-party inputs (PDK libraries, xschem examples) are **fetched at pinned revisions** by `tests/corpus/fetch.sh` into `tests/corpus/.cache/` (gitignored); goldens are generated by running a pinned xschem (`nix`) via `tests/corpus/golden.sh`. Nothing GPL is vendored.

## Release exit criteria

Corpus 100% pass with only annotated XFAILs; fuzzers ≥ 24 CPU-h per target with no new crash and a plateaued corpus; xschem-differential agreement count ≥ previous release with every difference triaged; byte-identical outputs on all four platforms; coverage not below the last release; D39 budgets met; known-gaps list written.

## Code rules that feed the oracles

TigerStyle asserts (≥ 2 per function on average, positive and negative space); bounded loops and queues; every table has a capacity.
